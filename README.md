# Coming Soon — portfolio placeholder

Static page, no build step. Open `index.html` or deploy the whole folder as-is
(GitHub Pages, Netlify, Vercel, any static host).

- `index.html` — the page, the game logic and a tiny template runtime
- `assets/` — sprites, plants, wife avatars, dithered backgrounds, music
- `assets/vendor/` — React 18.3.1 (production UMD builds), bundled so the page works offline

Fonts load from Google Fonts. Theme (day / sunset / night) follows the visitor's local time
and can be switched with the buttons next to "Sound On".

Live at https://aleksandrskvortsov.vercel.app — link-preview tags (og:image etc.) already point there.
